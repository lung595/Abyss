Abyss · One-click app install invite (NAK-291, D394)

Idea: installing is a dive. The depth gauge of the app (water-column direction) is the progress: the float goes down one mark per finished step, and stops where it fails. No spinner, no percentage.

Why it is not generic: the progress indicator is the app's own navigation gauge, so the invite already teaches the first thing the app will show.

Options

A · Inline band (recommended). Rises from the sand, the sea stays visible and usable above it. Cheapest: one item anchored in the popout, no veil, no new layer.

B · Small sheet. Centred over a veil, the app's panel pattern. Strongest focus, but it hides the sea for a question that can wait. Cost: veil, focus trap, Escape handling.

C · Toast-like card. Top right, lightest presence, but the progress and the copyable command are cramped at 304 px and it competes with the top bar. Cost: same as A plus a placement rule against the top bar.

Keyboard: Enter runs the primary button, Escape is "Not now". Focus order: primary, secondary, "Don't ask again", then the GitHub mark when present.
