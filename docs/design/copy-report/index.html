Abyss · NAK-521 · The "Copy report" row in Help

The anonymous diagnostics report, as the last row of the Help section ("Quick guide") of the built settings, under the six guide cards. Press the button: the report rises to the clipboard, water fills the button and three bubbles climb its edge, then it all leaves by itself. Beside the button the GitHub mark is always there: it opens a new issue for Abyss, where the report is pasted. Once the report is copied the mark takes the primary colour. Switch "Clipboard tool" to "Missing" to see the guided message. Every state is also drawn side by side under the panel.

Why it is not generic: the confirmation is neither a toast nor a green tick. In Abyss what is done comes up from the deep, so "copied" reads as water rising and bubbles reaching the surface.
